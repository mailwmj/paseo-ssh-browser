# Paseo SSH Browser

[English](README.md)

在 Paseo Desktop 中预览 SSH 主机上运行的 Web 应用，并在该主机与本机之间传输文件。SSH Browser 会为远程服务建立本地 SSH 端口转发，让你在代码运行于远程主机时，仍可使用浏览器、热更新和 DevTools。

![SSH Browser 显示远程 Web 服务](assets/web-services.png)

## 系统要求

- Paseo Desktop 和两端的守护进程版本均须为 **0.14.0-beta.1 或更高版本**。请在本机的 Paseo 主机和每台远程主机上安装相同版本的插件。
- 远程主机必须运行 Linux 并安装 `ss`。请在远程主机上安装 `curl`，以便识别 Web 服务并显示页面标题。
- 本机必须能够通过 `ssh <host>` 连接远程主机，且无需交互式提示。通过中继连接的主机也可以使用，前提是它们可通过 SSH 访问。
- 在 Paseo 内打开页面以及选择本地文件进行传输，都需要 Paseo Desktop。

## 安装

在 Paseo 的 **设置 → 插件** 中启用插件，然后在本机的 Paseo 主机和每台远程主机上安装以下 Git 源：

```text
git:mailwmj/paseo-ssh-browser
```

也可以使用 Paseo CLI，在每个守护进程上运行：

```sh
paseo plugin add git:mailwmj/paseo-ssh-browser
```

更新后，请重新加载两端的插件。现有代理会在下次重新打开时（下一条空闲提示之前）获得预览工具。插件会作为受信任代码在所在主机上运行；安装前请先检查源代码。

## 预览远程应用

1. 在远程工作区中启动 Web 服务器。
2. 在工作区中选择 **+ → SSH Browser**。选择已检测到的页面，或输入端口或 localhost URL；如有需要，也可以包含路径。若只检测到一个工作区页面，它会自动打开。
3. 使用 SSH Browser 侧边栏查看各主机上的服务、在系统浏览器中打开页面、重新连接端口转发，或停止转发。

在 Paseo Desktop 中连接的 SSH 主机会自动显示。对于通过其他方式连接的主机，请在 SSH Browser 侧边栏中添加其 SSH 地址。展开 **其他监听端口**，即可打开未被识别为 Web 页面的服务。

插件会尝试使用与远程服务相同的本地端口；如果该端口已被占用，则会选择其他端口。HTTPS 仍使用 HTTPS：证书必须受信任，且对预览使用的本地地址 `127.0.0.1` 有效。

### 让代理预览页面

代理可以调用 `open_remote_url`，传入远程 loopback HTTP 或 HTTPS URL，然后用 `browser_new_tab` 打开返回的 `localUrl`，并使用 Paseo 的浏览器工具检查标签页。该工具会创建隧道，但不会自行打开或验证页面。此工作流程只能连接一个 Desktop 浏览器主机，这样浏览器标签页才能在创建隧道的电脑上打开。如果没有符合条件的 Desktop，或连接了多个符合条件的 Desktop，请求会失败。可能需要明确要求代理预览页面；打印出来的 URL 不会自动打开。

## 传输文件

可以从工作区标题栏、**+** 菜单、Explorer 或 Command Center 打开 **文件传输**。如需隐藏某台主机上的这些入口，请在该主机的 **设置 → 插件 → SSH Browser** 中关闭 **显示文件传输**。正在进行的传输会继续。

- **发送到主机：**选择目标文件夹，从本机添加文件，然后选择 **发送**。目标文件夹默认为工作区文件夹，并会按工作区记住。
- **下载到本机：**选择工作区中的文件，或输入以 `/`、`~/`、`./` 或 `../` 开头的明确远程路径，然后按 Enter。文件按修改时间排序，初始加载 20 个；每次选择底部的 **加载更多** 会再加载 20 个。搜索范围包含尚未加载的工作区文件。

下载默认保存在 `~/Downloads/Paseo/<workspace name>/` 下；可以在面板中更改接收文件夹。传输会显示进度，并可取消或重试。不会覆盖已有文件，而是添加编号后缀。暂不支持文件夹、拖放和断点续传。

## 隐私与限制

本地插件使用你现有的 SSH 配置和凭据运行 SSH 命令。插件界面打开期间，每 10 秒扫描一次远程监听端口和进程信息。插件会通过 HTTP 探测监听端口；必要时也会使用 HTTPS，以识别页面；HTTPS 探测不会验证证书。端口转发仅监听本机 loopback 地址，并会在连接断开或插件停止时终止。文件通过 SSH 流式传输，不会经过代理。

最近使用的预览地址保存在本地 Paseo 插件设置中，其中可能包含敏感查询参数；如有需要，可在工作区面板中清除。插件会使用部分 Paseo Desktop 内部接口来查找主机并在插件副本之间通信，因此未来的 Paseo 更新可能会导致这些功能无法使用。详情请参阅 [OVERVIEW.md](OVERVIEW.md)。

## 开发

```sh
npm install
npm run typecheck
npm test
```

如果 `ssh localhost` 无需交互式提示即可运行，测试套件还会执行 SSH 集成测试。
